# 🎮 Siddharth Brahmankar · Interactive Portfolio

A Mario-style side-scroller that works as my portfolio. Walk through the level and jump into the **HIT ME???** boxes to reveal my education, experience, research, projects, skills and contact details.

## 🕹️ Controls

| Action | Keyboard | Phone / tablet |
|---|---|---|
| Move | ← → | Red arrow buttons |
| Jump | ↑ or Space | Up button |
| Reveal a section | Jump into a box from below | Same |
| Music | Button in the top-right | Same |

## 🧱 Built with

Plain HTML, CSS and JavaScript (jQuery), hosted on GitHub Pages. No build step: open `index.html` in a browser to run it locally.
